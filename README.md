# Procurator Nodus

Procurator Nodus (PN) is a self-hosted platform that runs several applications on one server from a single core. It gives them shared, managed capabilities (identity and sign-in, data across databases, secrets, APIs between applications, network controls and an admin console) while keeping each application isolated.

**Status:** pre-release, in active development.

**License:** PN will be released as free, open-source software under the Apache-2.0 license. This repository holds only the project's landing page, also under Apache-2.0.
