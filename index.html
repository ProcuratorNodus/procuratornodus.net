Procurator Nodus

One core.Many applications.

Procurator Nodus is a self-hosted platform that runs your applications on one server, gives them shared, managed capabilities, and keeps every application apart.

Watch the project on GitHubPre-release

What it is

Build each application on the capabilities it needs. Run them side by side without letting them reach into one another.

  • Identity and sign-in

    Accounts, sessions and permissions, managed once and used by the applications you choose.

  • Data across databases

    Work with several databases through one consistent interface.

  • Secrets

    Keep credentials and keys in one managed place, handed only to the application that needs them.

  • APIs between applications

    Let applications offer and use each other's services on terms you set.

  • Network controls

    Decide what your applications can reach, and what can reach them.

  • An admin console

    Install, configure and watch everything from one place.

How it works

At the center is the core. It is the one thing you install, and it keeps applications separate from each other.

Around it sit spokes. Each spoke provides one capability, such as sign-in, data or secrets. Applications use the spokes they need, and every request between parts passes through the core.

You install one package, run a command-line setup, then manage the rest from the admin console.
